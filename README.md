# ArtGift — Java Mini Project

## Project Overview

ArtGift is an online art marketplace concept designed to connect artists with customers. The platform focuses on artwork discovery, artist portfolios, customized artwork requests, and order management.

## Objectives

- Provide a platform for displaying artwork.
- Help customers discover artists and their creations.
- Support customized artwork requests.
- Maintain artwork and order information in a database.
- Demonstrate Java programming and database connectivity.

## Technologies

The proposed Java implementation uses:

- Java
- JDBC
- MySQL
- Java Swing or JavaFX, or a Java web interface using Servlets and JSP

The final technology list must reflect the actual implementation.

## Main Features

1. User registration and login.
2. Artist profile management.
3. Artwork listing management.
4. Artwork browsing and searching.
5. Custom artwork requests.
6. Basic order management.
7. Database storage and retrieval.

## Project Structure

The project can be organized into Java source files, database scripts, documentation, screenshots, and test cases.

## Installation

1. Install the JDK.
2. Install and configure MySQL.
3. Create the ArtGift database.
4. Configure the database connection.
5. Add the MySQL JDBC driver.
6. Open the project in a compatible Java IDE.
7. Run the main Java class.

Complete these steps only after the corresponding source code and database have been created.
